# Sistema de Gestión de Consultorio Odontológico

## Descripción

Este proyecto consiste en un sistema desarrollado en Python para gestionar la información de los clientes de un consultorio odontológico.

El programa permite registrar clientes, calcular el valor de los servicios, consultar información y obtener estadísticas sobre las atenciones realizadas.

## Datos registrados

Para cada cliente se registra:

- Cédula
- Nombre
- Teléfono
- Tipo de cliente
- Tipo de atención
- Cantidad de procedimientos
- Valor de la cita
- Valor de la atención
- Total a pagar

## Tipos de cliente

El sistema maneja tres tipos de clientes:

- Particular
- EPS
- Prepagada

## Tipos de atención

El sistema permite registrar:

- Limpieza
- Calzas
- Extracción
- Diagnóstico

## Funciones principales

El programa permite:

1. Registrar varios clientes.
2. Mostrar los clientes registrados.
3. Buscar un cliente mediante su cédula.
4. Mostrar el total de clientes.
5. Calcular los ingresos totales.
6. Contar los clientes que tienen extracción.
7. Ordenar los clientes de acuerdo con el valor de la atención.
8. Calcular automáticamente el total a pagar.
